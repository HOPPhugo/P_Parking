Analyse :

	Boucle de jeu {
		- Boucle while qui entoure tout.
		- Appel d'une fonction qui affiche toutes les informations.
		- Console.ReadLine(); pour attendre ce que le joueur veux faire selon les informations du "Menu".
		- Un Switch qui gère l'entrée du joueur. {
			- Option 1 : Appeler "EnterVehicule".
			- Option 2 : Appeler "ExitVehicule".
			- Option 3 : Appeler "ShowStats".
			- Option 4 : Appeler "SearchVehicule".
			- Option 5 : Appeler "DayStatistics".
			- Option 6 : Appeler "TransactionHistory".
			- Option 0 : Appeler "CloseApp".
			- Option Default : Appeler "ShowError".
		}
		- Quand on est sorti des fonctions précédentes (après avoir appuyer sur "Enter") appeler "ShowStats".
	}
	Fonctions {
		- EnterVehicule : {
			- Console.Clear();
			- Demander l'utilisateur d'entrer un plaque d'immatriculation valide.
			- Appeler "CheckLicensePlate".
			- Si "CheckLicensePlate" retourn "true", crée un nouveau objet "Voiture". Autrement, appeler "ShowError".
			- Créer un objet "Ticket".
			- Attendre que l'utilisateur appuie sur "Enter".
		}
		- ExitVehicule : {
			- Console.Clear();
			- Demander à l'utilisateur un plaque d'immatriculation ou une place existante. Autrement Apppeler "ShowError".
			- Appeler "ShowTicket".
			- Afficher l'heure de sortie (donc l'heure actuelle).
			- Appeler "CalculatePrice" et afficher le montant.
			- Demander à l'utilisateur s'il souhaite vraiment sortir {
				- Oui : Rendre la place libre.
				- Non : Afficher que la place vas rester tel-quel.
				- Autre : Appeler "ShowError" et reposer la question.
			}
			- Attendre que l'utilisateur appuie sur "Enter".
		}
		- ShowStats : Uniquement affichage de toutes les informations du parking (etat du parking, plan du parking, véhicules présents, Menu Principal) en utilisant un console.clear(); et réécriture du totale.
		- SearchVehicule : {
			- Demander à l'utilisateur un plaque d'immatriculation ou une place existante. Autrement Apppeler "ShowError".
			- Appeler "ShowStats".
			- Attendre que l'utilisateur appuie sur "Enter".
		}
		- DayStatistics : Console.Clear(); puis Affiche uniquement les statistiques du jour. Puis attends que l'utilisateur appuie sur "Enter".
		- TransactionHistory : Console.Clear(); puis Affiche uniquement l'historique des transactions. Puis attends que l'utilisateur appuie sur "Enter".
		- CloseApp : {
			- Demander à l'utilisateur s'il veux vraiment quitter. {
				- Oui : Fermer l'application en utilisant "Environement.Exit(0)";
				- Non : Afficher le choix de l'utilisateur puis attendre qu'il appuie sur "Enter".
			}
		}
		- ShowError : ⚠️SE REFERER AU "BoucleErreurSchema" DANS LE DOSSIER "Schema"⚠️ Selon le chiffre donné, gère avec un switch toutes les erreurs possible, attends que l'utilisateur appuie sur "Enter".
		- ShowTicket : Affiche toutes les informatioms utiles à savoir sur le ticket (Heure d'entrée, prix, place, voiture liée), (pour récupérer l'heure actuelle utiliser "string datetime = DateTime.Now.ToString("hh:mm:ss tt")").
		- CheckLicensePlate : Vérifie si la plaque d'immatriculation est valide (pour vérifier faire un foreach sur l'entrée du joueur qui sera en string, puis vérifier si c'est égale à n'importe quel chiffre, si ce n'est pas un chiffre, l'ajouter dans un tableau "lettre" puis compter);
		- CalculatePrice : Calcule le montant totale avec la durée et le prix du ticket. Retourne uniquement le montant.
	}
	Classes {
		- Parking : Toutes les informations concerant le parking, avec un tableau avec toutes les places de park du parking, une liste de tout les véhicule qui sont venu et une list de tout les tickets. Toutes les donctions tournes là dedans.
		- Place : Numero de place, statut, nombre de fois qu'elle ai été utilisée, quel voiture l'occupe actuellement.
		- Voiture : Plaque d'immatriculation, statut.
		- Ticket : plaque d'immatriculation reliée, numero de ticket, heure d'entrée, prix, heure de sortie, prix totale à la sortie, numero de place du vehicule.
	}
